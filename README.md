# NourishBot — Multimodal AI Nutrition Assistant

NourishBot is a Gradio application that uses IBM watsonx.ai and CrewAI to identify ingredients in food images, apply dietary restrictions, estimate nutrition, and suggest recipes.

## Features

- **Ingredient detection:** Uses a multimodal watsonx.ai model to identify visible ingredients.
- **Ingredient cleaning:** Standardizes names and removes duplicates.
- **Dietary filtering:** Filters ingredients against user-provided restrictions.
- **Nutrition analysis:** Estimates calories, macronutrients, vitamins, and minerals, with uncertainty clearly acknowledged.
- **Recipe suggestions:** Produces recipe ideas using filtered ingredients, dietary restrictions, serving count, and an optional calorie goal.
- **Structured outputs:** Pydantic models describe and validate the nutrition and recipe result shapes.

Nutrition estimates are generated by AI and are not laboratory measurements or medical advice. Always check food labels and allergens and verify recipe safety before use.

## Architecture

- `app.py` — Gradio interface and workflow entry points.
- `src/crew.py` — CrewAI agents, tasks, sequential workflows, and watsonx LLM configuration.
- `src/tools.py` — image extraction and text-generation tools backed by watsonx.ai.
- `src/models.py` — Pydantic schemas for recipe and nutrition outputs.
- `src/config/agents.yaml` — agent roles, goals, and backstories.
- `src/config/tasks.yaml` — task descriptions and expected outputs.

The **Analysis** workflow runs ingredient identification, cleaning, dietary filtering, and nutrition analysis. The **Recipe** workflow runs those steps and then generates recipe suggestions.

## Prerequisites

- Python 3.11 recommended.
- Git.
- IBM watsonx.ai credentials with access to the configured text and vision models.

## Setup

Clone this repository and switch to the implementation branch:

```bash
git clone https://github.com/rd2080/IBM_Nourishment-app_Implementation.git
cd IBM_Nourishment-app_Implementation
git checkout 1-start
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Create a root-level `.env` file (do not commit it):

```dotenv
WATSONX_URL=https://eu-de.ml.cloud.ibm.com
WATSONX_APIKEY=your_ibm_cloud_api_key
WATSONX_PROJECT_ID=your_watsonx_project_id
```

Use the correct regional URL for your watsonx.ai project. The variable name must be `WATSONX_APIKEY` exactly.

## Run

```bash
python app.py
```

Open the local URL printed by Gradio (normally `http://127.0.0.1:7860`). Upload a food or ingredient image, optionally specify dietary restrictions and portion details, then choose **Analyze Nutrition** or **Suggest Recipes**.

## Validate

Run syntax and model checks:

```bash
python -m py_compile app.py src/crew.py src/tools.py src/models.py
python -c "from src.models import RecipeSuggestionOutput, NutrientAnalysisOutput; print('Models imported successfully')"
python -m pip check
```

The two main workflows make live watsonx.ai requests and therefore require valid credentials, model access, and an internet connection.

## Configuration and secrets

- Keep `.env`, virtual environments, and Python cache files out of Git.
- Never paste API keys into source code, logs, screenshots, or commits.
- If a key is exposed, revoke it and create a replacement.

## Limitations

- Ingredient identification depends on image quality and may be uncertain.
- Nutrition values are estimates and depend on portion sizes and ingredients the image may not reveal.
- Dietary filtering cannot guarantee allergen safety where labels or preparation details are unknown.
- Model availability and pricing are controlled by IBM watsonx.ai and the selected account/project.
